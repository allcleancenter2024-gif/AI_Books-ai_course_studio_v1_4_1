# AI 강의 활용 Studio v1.26.3 [2026-09-10]

이번 릴리스의 변경 내역은 [v1.26.3 변경 기록](CHANGELOG_v1.26.3.md)을 확인하세요. 기존 EXE는 재패키징하지 않았으므로 새 소스 실행에는 `run_windows.bat`를 사용합니다.

## 실행
1. ZIP을 새 폴더에 압축 해제합니다.
2. `run_windows.bat`를 실행합니다.
3. 브라우저에서 `http://127.0.0.1:8765`가 열립니다.
4. 로그인 화면에서 관리자 계정으로 접속합니다. 비밀번호는 소스 코드에 저장되지 않으며, DB에는 보안 해시만 저장됩니다.

문제가 있으면 `run_windows_debug.bat`를 실행합니다.

로그인에 5회 연속 실패하면 해당 이름·로컬 접속 환경에서는 5분 뒤 다시 시도할 수 있습니다. 인터넷에 공개 배포할 때에는 HTTPS를 사용하고 `AI_COURSE_STUDIO_COOKIE_SECURE=1`을 설정하세요.

## 기본 DB 및 선택적 외부 이전

프로그램의 실제 기본 RDBMS는 SQLite 3이며 DB 파일은 `data/studio.db`입니다. 과정·교재·참고자료·검색 벡터가 이 파일에 저장되므로 Docker를 실행하지 않아도 프로그램이 작동합니다. 아래 MongoDB/PostgreSQL 스택은 서버 이전·분석을 위한 **선택적 외부 복제 환경**입니다.

| 구성 요소 | 접속 주소 | 용도 |
|---|---|---|
| MongoDB | `mongodb://127.0.0.1:27018` | 수집 원문·비정형 참고자료 |
| PostgreSQL | `127.0.0.1:5434` | 앱 서비스용 정형 데이터 |
| Mongo Express | `http://127.0.0.1:8082` | MongoDB 웹 관리 GUI |
| pgAdmin | `http://127.0.0.1:5051` | PostgreSQL 웹 관리 GUI |
| Node.js API | `http://127.0.0.1:3001/health` | Prisma/Mongoose 멀티 DB 연결 상태 |

1. `.env.example`을 `.env`로 복사하고, 모든 `CHANGE_ME` 값을 긴 무작위 비밀번호로 변경합니다. `.env` 파일은 Git에 올리지 마세요.
2. `docker compose up -d --build`를 실행합니다.
3. `http://127.0.0.1:3001/health`에서 두 DB가 모두 `true`인지 확인합니다.
4. `python scripts/sync_sqlite_to_multidb.py`를 실행하면 SQLite 원본을 외부 DB로 이전할 수 있습니다. 이 스크립트는 SQLite를 변경하지 않으며 반복 실행해도 중복 생성되지 않습니다.

Docker 내부에서는 `mongodb:27017`, `postgres:5432` 서비스 이름으로 통신합니다. MongoDB 문서의 `legacy_source_id`와 PostgreSQL `ServiceRecord.mongoId`로 두 DB의 레코드를 연결합니다. 수집일과 엔터티 유형 인덱스도 생성됩니다. `data/legacy_archive`의 SQLite 파일은 읽기 전용 복구용 백업이며, 실행 DB가 아닙니다.

Mongo Express는 별도 HTTP Basic 인증을 사용합니다. Compass를 사용할 때에는 `.env`의 MongoDB 관리자 계정으로 `127.0.0.1:27018`에 연결하세요. pgAdmin에서는 Host를 `postgres`, Port를 `5432`로 추가하면 컨테이너 네트워크 안에서 연결됩니다.

## 권장 사용 순서
1. AI Provider 연결/테스트
2. 참고자료 추가
3. 필요한 자료 체크
4. 필요하면 `선택 자료 AI 요약`
5. 1주 교재로 먼저 테스트
6. 전체/구간 교재 생성

## 참고자료
지원 업로드: md, markdown, txt, html, pdf, pptx, png, jpg, jpeg, webp

웹페이지는 공개 URL을 입력합니다. ChatGPT의 공개 공유 페이지도 일반 웹페이지처럼 접근 가능한 경우 참고자료로 추가할 수 있습니다. 로그인이나 스크립트 실행이 필요한 사이트는 본문 추출이 제한될 수 있습니다. 선택한 공개 웹 자료는 교재 생성 전에 하루 1회까지 자동 갱신되고, 실패해도 마지막으로 검증·벡터화한 내용은 유지됩니다.

업로드 원본은 추출 직후 삭제합니다. 데이터베이스에는 텍스트·필수 메타데이터·검색용 벡터 청크만 보관하므로 저장 공간을 줄이면서 교재 생성 시 관련 부분만 검색합니다. 원본 이미지 자체를 다시 AI로 분석해야 하는 경우에는 해당 파일을 다시 첨부하세요.

자료 요약은 LM Studio·Ollama처럼 컨텍스트가 작은 로컬 모델에서도 원문을 안전한 크기의 조각으로 나누어 요약한 뒤 단계적으로 통합합니다. 진행 중에는 조각 요약·통합·파일 생성 상태가 표시되며, 완료 후에는 자료별 Markdown 요약 파일을 바로 열거나 다운로드할 수 있습니다.

1주 교재와 전체·구간 교재도 생성 단계와 진행률을 표시하며, 완료된 교재는 서버의 Markdown 파일로 저장됩니다. 결과 영역의 `교재 내용 보기`로 새 창에서 확인하거나 `Markdown 다운로드`로 저장할 수 있습니다. 오류가 나면 원인별 해결 방법이 도움말 카드에 표시됩니다.

YouTube 영상은 공개 자막과 자동 자막을 우선 가져옵니다. 자막이 없거나 YouTube가 요청을 제한하면 제목·채널·URL을 DB 참고자료로 남기고, 자료 목록에서 `자막 다시 가져오기`를 실행할 수 있습니다. 자막이 없는 영상의 실제 발화 내용은 추측해서 교재에 넣지 않습니다.

영상 URL은 기본적으로 링크를 안전하게 보관합니다. 실행 환경에 `youtube-transcript-api`가 이미 설치되어 있고 공개 자막이 있으면 자막도 가져올 수 있으며, 그렇지 않아도 Gemini Notebook 자료팩에 URL 정보가 포함됩니다.

## Gemini Notebook
`Gemini 열기`로 Gemini 앱을 열고, `Gemini Notebook 자료팩` ZIP에서 필요한 파일을 Notebook의 소스로 추가합니다.
Google Docs/Slides를 향후 Drive 소스로 직접 연동할 경우 Google 공식 안내에 따라 Drive 권한이 포함된 로그인이 추가로 필요할 수 있습니다.

## 보안/성능
- API 키는 SQLite에 저장하지 않습니다.
- 외부 URL은 사설/로컬 네트워크 접근을 차단합니다.
- 파일 하나당 최대 500MB까지 업로드할 수 있습니다. 1MB 청크로 디스크에 저장하며 PDF는 페이지별, PPTX는 슬라이드별, 텍스트·HTML은 블록별로 분석합니다.
- 추출 텍스트와 AI 입력은 별도의 상한을 적용하여 대용량 원본이 메모리나 모델 문맥을 독점하지 않게 합니다.
- 매우 긴 문서는 일부 텍스트만 AI 문맥으로 사용합니다.
- 이미지 OCR 패키지를 기본 설치하지 않아 프로그램을 가볍게 유지합니다. 대신 이미지 입력을 지원하는 AI 모델로 요약할 수 있습니다.

## 작업 상태와 취소

장시간 교재 생성·자료 요약 작업의 상태는 SQLite `job_states`에 저장되어 서버 요청이 끝나도 진행 상태와 완료 결과를 조회할 수 있습니다. 인증된 세션에서 `GET /api/jobs/{job_id}`로 상태를 확인하고, 필요하면 `POST /api/jobs/{job_id}/cancel`로 취소할 수 있습니다. 작업 취소는 이후 생성 단계의 경계에서 안전하게 반영되며, 기존 자료·교재 파일은 삭제하지 않습니다.


## 실행 버전 보호

`run_windows.bat`는 8765 포트에서 이전 AI 강의 활용 Studio가 실행 중인지 버전까지 확인합니다. 예전 Studio가 확인되면 Windows에서 해당 Studio 서버만 종료한 뒤 v1.26.3을 시작합니다. 다른 프로그램이 8765를 사용 중이면 자동 종료하지 않습니다.
