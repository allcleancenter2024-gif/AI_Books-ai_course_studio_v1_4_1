외부 DB 구성 및 SQLite 자료 이전 방법
  1. .env.example을 .env로 복사하고 모든 CHANGE_ME 비밀번호를 변경합니다.
  2. 프로젝트 폴더에서 docker compose up -d --build를 실행합니다.
  3. 위의 관리 도구 버튼에서 로그인합니다. PostgreSQL 서버 등록 시 Host는 postgres, Port는 5432입니다.
  4. python scripts/sync_sqlite_to_multidb.py를 실행하면 SQLite 원본을 외부 DB로 복제합니다.

외부 DB가 중지되어도 Studio의 기본 SQLite 저장과 교재 생성에는 영향을 주지 않습니다.

15. 웹 교재 발행

Studio에서 내려받은 Markdown을 공개 검토한 뒤 Publisher 원고 규약에 맞춰 발행합니다. 생성된 차시는 주차별 handoff API로 학생용·강사용·통합 콘텐츠와 품질·승인 상태를 전달할 수 있습니다. Publisher는 별도 실행 프로그램입니다.

이 PC의 웹 교재 열기공개 준비 상태 확인

승인되지 않은 차시는 발행하지 않습니다. 연결되지 않으면 Publisher 실행 상태를 확인하세요. 이 링크는 접속한 기기의 localhost를 가리킵니다. 개인정보 처리방침·이용약관은 초안이며 정식 공개는 대기 중입니다.
